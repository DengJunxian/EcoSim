# Homepage figures

The architecture follows the paper's causal clock. Four cards show preparation, social behavior, decisions and settlement. A return arrow connects committed prices and portfolios to the next step.

The results figure has three panels with distinct units. The market panel uses one marker per archived trajectory and groups observations by baseline. The branch panel shows all 27 event steps and the shared pre-event checkpoint for two branches of one parent. The cognition panel counts changes in economic action signatures out of the same 27 fixed-observation pairs per backend. None of the panels pools the designs into a single estimate.

The palette pairs navy with teal, amber and slate. Marker shapes identify matched world seeds, and line styles supplement color in the branch plot. Solid backgrounds keep embedded figures legible in both GitHub themes. SVG is for the README, PDF for vector reuse and PNG for raster preview.
